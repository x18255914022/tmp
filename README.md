# 🧬 Salmon Tracker — Трекер «Выборка × Локус»

Автономное десктоп-приложение для отслеживания лабораторного прогресса генетической работы с лососёвыми на уровне **выборка × локус** (batch × locus).

## Что это

- Отслеживание проектов, выборок и статусов по каждому локусу
- Статусы: ДНК-экстракция, ПЦР, электрофорез
- Автоматический расчёт готовности к анализу
- Справочник из 10 стандартных локусов (редактируемый)
- Экспорт в Excel (.xlsx)
- Резервное копирование базы данных
- Светлая и тёмная темы
- Полностью офлайн — никаких серверов, облаков, интернета

## Требования

- **Windows 10/11** (также работает на macOS и Linux)
- **Node.js 18+** — [скачать](https://nodejs.org/)
- **Git** (опционально)

## Установка и запуск

### 1. Установить зависимости

```bash
cd salmon-tracker
npm install
```

### 2. Запустить в режиме разработки

В **двух отдельных терминалах**:

**Терминал 1** — запустить интерфейс:
```bash
npm run dev:renderer
```

**Терминал 2** — запустить Electron (после того как Vite стартует):
```bash
npm run dev:main -- --dev
```

### 3. Собрать для продакшена

```bash
npm run build
npm start
```

### 4. Создать Windows-инсталлятор

```bash
npm run dist
```

Инсталлятор появится в папке `release/`.

## База данных

SQLite-файл хранится в:
- **Windows:** `%APPDATA%\salmon-tracker\salmon-tracker.db`
- **macOS:** `~/Library/Application Support/salmon-tracker/salmon-tracker.db`
- **Linux:** `~/.config/salmon-tracker/salmon-tracker.db`

## Статусы

### ДНК-экстракция
- **Не начато** — работа не начата
- **Выполнено** — ДНК выделена
- **Проблема** — проблема с экстракцией

### ПЦР
- **Не начато** — работа не начата
- **Выполнено** — амплификация прошла успешно
- **Повтор ПЦР** — нужен повтор ПЦР (пустые дорожки, нет амплификации)
- **Проблема** — критическая проблема

### Электрофорез
- **Не начато** — работа не начата
- **Выполнено** — полосы читаемы, аллели определимы
- **Повтор фореза** — ПЦР прошла, но гель нечитаемый
- **Проблема** — критическая проблема

### Готово к расчётам
Автоматически: ДНК = Выполнено + ПЦР = Выполнено + Электрофорез = Выполнено.
